# Willow We Love — лендинг кофейни

План и спецификация — в `PLAN.md`, читай его перед каждой задачей. Вайрфрейм (desktop 1280px и живое демо блока 08) — `docs/wireframe.html`, открывается в браузере.

## Команды

- `npm run dev` — dev-сервер
- `npm run build` — проверка типов и сборка
- `npm run lint` — oxlint
- `npm run format` — Prettier

## Правила

- Одна задача — один этап или один блок из `PLAN.md`; после неё проверка в браузере на 375 и 1440px.
- GSAP импортируется только из `@/lib/gsap`, анимации — только в `useGSAP` со `scope` на корень секции.
- Анимируемые элементы помечаются `data-`атрибутами (`data-reveal`, `data-step-circle`), а не классами Tailwind.
- Начальные состояния анимаций задаются в JS (`gsap.from` / `gsap.set`), в разметке всё в конечном, видимом состоянии.
- Сайт на трёх языках (sr, ru, en). Переводимые тексты — в `src/i18n/locales/{ru,en,sr}.ts`, в компонентах берутся через `useLang()`; `ru.ts` задаёт структуру, новый ключ добавляется во все три файла. Строк в компонентах нет.
- Данные без перевода (ссылки, контакты, часы) — в `src/data/content.ts`, меню — в `src/data/menu.json`.
- Анимации, которые режут или измеряют текст (SplitText, расчёт ширин), должны пересобираться при смене языка: `useGSAP(..., { dependencies: [lang], revertOnUpdate: true })`.
- Цвета и шрифты — только через токены `@theme` в `src/index.css`.
- Новые библиотеки — только с согласия.
- Правки анимаций и решения по ходу сразу вносятся в `PLAN.md`.
